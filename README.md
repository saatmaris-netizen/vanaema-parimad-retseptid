# Vanaema parimad retseptid

Interaktiivne eestikeelne küpsiste e-kaart kuue retseptiga. Vajuta kingikarbi lehvile ja seejärel küpsisele, et avada retsept.

## Kasutamine

Ava `index.html` veebiserveris. p5.js laaditakse internetist. Veebis avaldamiseks sobib staatiliste lehtede majutus, näiteks GitHub Pages.

## Failid

- `index.html` — e-kaart ja retseptid
- `sketch.js` — p5.js karbianimatsioon
- `pildid/` — küpsisefotod ja taustajoonistus

Retseptide algallikate viited on retseptide juures. Fotode ja retseptide õigused kuuluvad nende õiguste omanikele.
